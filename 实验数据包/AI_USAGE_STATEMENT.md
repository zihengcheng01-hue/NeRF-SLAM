# AI Usage Statement

## AI Tools Used

In the completion of this project, the following AI tools were utilized:

1. **Claude (Anthropic)** — Used for:
   - Generating the Word document template and formatting
   - Assisting with code structure for evaluation scripts
   - Proofreading and polishing the academic writing

2. **ChatGPT (OpenAI)** — Used for:
   - Debugging Python scripts (matplotlib visualization, data processing)
   - Rewording certain sections of the paper for clarity

## Scope of AI Assistance

- All AI-generated content has been **carefully reviewed, edited, and approved** by the author.
- The core ideas, algorithm design, experimental analysis, and conclusions are the **original work of the author**.
- AI tools were used primarily as **writing assistants and code debuggers**, not as substitutes for intellectual contribution.

## Transparency

This statement is provided in accordance with the course policy on AI tool usage. No AI tool was used to fabricate experimental results or plagiarize existing work.
